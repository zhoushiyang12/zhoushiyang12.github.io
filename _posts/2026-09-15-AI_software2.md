上次尝试了Trae之后，这次又尝试了一下WorkBuddy（手机端）。总体感觉WorkBuddy交付的结果更好，但速度慢（近10分钟返回一次结果），给的免费额度太少，免费额度下只够开发了一个“笑脸墙程序”，一个月免费500*消耗的也很快；之前试Trae返回结果更快（2_3分钟），便于多次迭代。

下面是我用WorkBuddy开发的，用于在大屏幕展示企业、班级笑脸墙的程序（单机使用Html5），可以直接保存到本地单机使用。

# 笑脸墙

以下是各模块功能介绍和操作指南：

## 1. 浏览地图
地图上的每个省份以红黄分层设色呈现，点击任意省份即可查看该省所有成员笑脸；再次点击或点击左上角菜单「显示全国」可回到全国视图。

## 2. 查看人员信息
点击地图周围的头像，会弹出半透明悬浮窗（窗口大小、头像、字号会随屏幕尺寸自适应），显示姓名、籍贯、民族、出生日期（年月日）、班级、爱好、特长及座右铭。在详情中可把该成员设为突出显示，其笑脸会立即以金红光环在墙上高亮（并略微放大），并在动画演示中优先出场；可同时突出显示多名人员。

点击详情中的头像或下方任意个人照片缩略图，可全屏放大查看，支持 ← / → 切换上一张 / 下一张，按 Esc 或点空白处关闭。

点击省份弹出的成员窗口，可用标题栏右侧的 ✕ 关闭；点击地图或舞台的空白区域同样可关闭该窗口与人员详情窗口。

## 3. 动画演示
点击右下角的「动画演示」按钮开始演示；点击其右侧的齿轮按钮 ⚙ 可展开演示形式选择面板（再次点击收起），共 6 种形式：

聚焦：随机依次放大单个成员并展示其详细资料，并把该成员的全部个人照片以缩略图墙展示（可点击切换、自动轮播）；
轮播：全屏循环播放成员照片，底部圆点可直接跳转；
照片墙：把全体人员的所有照片随机散落铺满全屏（带错峰弹入动画，不再整齐排列），逐个金色光环旋转 + 放大突出显示当前成员的姓名，每张照片停留约 3 秒；
翻牌：中央 3D 扑克牌堆叠，逐张飞出切换；
胶片：电影胶片式横向滚动条，配合中央大画面聚焦；
幻灯片：轮播所有人员的全部照片，每一切换使用一种酷炫转场：淡入 / 飞入 / 飞出 / 溶解 / 百叶窗 等循环出现。
再次点击按钮、点击空白处或按 ESC 键退出；演示中按空格或 ← → 切换上 / 下一位。演示窗口、照片大小与菜单栏图标均会随屏幕尺寸自动缩放。

## 4. 添加 / 导入人员
点击左上角菜单 →「添加人员」可手工录入；点击「导入文件夹」可选择一整个文件夹，程序会自动识别符合命名规则的照片。

命名示例：张伟-山东-汉族.jpg
其中姓名、省份、民族为必填项，可用 -、—、_ 分隔；其余字段（出生日期、班级、爱好、特长、座右铭）可后续在详情面板编辑补充。

## 5. 人员信息文本导入 / 导出（TXT）
左上角菜单 →「导出人员(TXT)」会把所有成员的文本资料保存为一个 .txt 文件；「导入人员(TXT)」可选择该文件批量录入。

每行一位成员，按顺序 8 个字段，用空格分隔（中英文空格均可，连续多个空格视为一个）：

姓名 省份 民族 生日 爱好 特长 座右铭 班级
缺省项用星号「*」代替，不要留空；
姓名与省份为必填，省份需可识别（如「广东省」或「广东」）；
生日建议用 YYYY-MM-DD（也可只填 YYYY-MM）；
以 # 开头的行为说明文字，导入时自动跳过（导出的文件自带完整格式说明）；
导入时以「姓名 + 省份」为关键字：已存在则更新资料，不存在则新增，已录入的个人照片不会被覆盖。
为避免与分隔符混淆，字段内部的原空格导出时会替换为下划线「_」。
## 6. 生日提醒
在「显示设置 → 生日提醒」中开启后，未来 7 天内过生日的成员会在笑脸墙上显示 🎂 标记（随笑脸框大小自动放大）与呼吸式红色光环，详情面板顶部也会出现「🎂 生日」标签；左下角自动出现 🎂 生日气泡（位于「成员 / 省份」统计窗口上方，不压盖），气泡上的数字代表近 7 天的生日人数，点击气泡可展开 / 收起名单列表，点击条目可快速打开成员详情，再次点击卡片外任意位置自动折叠。系统按你设定的时间（默认每天 06:00，使用本机系统时间）自动刷新标记。

## 7. 数据备份
「保存数据」会把全部成员信息、显示设置、笑脸布局与个人照片打包成一个 .json 文件保存到本地；换设备或重装后，用「载入数据」选择该文件即可完整还原（导入会替换当前全部数据）。若只需文本资料，可使用「导出 / 导入人员(TXT)」。

##  8. 快捷操作
ESC：关闭当前弹窗 / 退出演示 / 清除省份筛选
空格：演示模式下切换到下一位
← →：轮播演示模式下切换上一张 / 下一张
点击空白区域：关闭省份成员窗口与人员详情窗口
右上角齿轮 ⚙：展开 / 收起动画演示形式选择面板
左上角笑脸按钮：展开 / 收起功能菜单，展开时笑脸变为大笑
全屏显示：适合会议大屏、展厅 kiosk
拖动头像：鼠标 / 手指按住地图上的笑脸可手动摆放到任意位置，松手即保存
显示设置：左上角菜单 →「显示设置」可更换背景、调整照片大小与边框形状、开关笑脸周边旋转动画，并支持复位布局
默认背景为中国红（透明度 90%）；笑脸周边的旋转光环动画默认关闭，可在「显示设置 → 主页笑脸框 → 旋转动画」中开启。
